# 模型准备与双模式

本机已实测 Ollama 的 qwen2.5:3b（回答）与 qwen3-embedding:0.6b（向量，1024 维）。16GB CPU 设备一次执行一个模型任务，调用结束卸载权重。

设置页添加两个配置，容器连接地址为 `http://host.docker.internal:11434`。先分别测试能力，再选择默认回答/向量模型。默认模型可以不同接入方式，也可以全部本地。

首次安装 Ollama、下载权重、构建镜像需要联网。设置页下载按钮会明确确认联网；可查询持久化下载进度。Windows Ollama 默认权重目录为 `%USERPROFILE%/.ollama/models`。

API 配置分别使用 OpenAI 兼容 `/chat/completions`（SSE）和 `/embeddings`，服务地址填到协议根，例如 `https://供应商/v1`。不支持私有协议自动识别。问题和召回文字会发往回答服务，全文切片会发往向量服务。

密钥只在本机 `data/secrets` 保存，普通设置及默认备份不包含密钥。移除密钥后必须新建配置才能重新提供密钥。配置版本不可变，历史回答保留原配置含义。能力测试不会自动更换默认配置。

真实 API 尚无用户密钥，因此仅协议契约测试通过，不能据此宣称任意供应商兼容。服务不可达、鉴权失败、缺模型时不自动回退。
