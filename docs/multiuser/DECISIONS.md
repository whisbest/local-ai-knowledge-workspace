# 多用户实施决策

状态：P0～P11本地开发及部署包已完成，采用已授权V2计划的推荐基线。真实外部API与公网部署保持待环境验收。

- 当前工程在 `AI知识库问答系统`；旧版 data 保留，开发使用独立 PostgreSQL 和数据目录。
- 单机 V1 保持原实现和测试，V2 在同一工程复用解析与页面，独立数据库迁移链和入口，避免正在运行的旧版被修改。
- PostgreSQL 17；带所有者过滤的浮点数组与有界 NumPy 精确检索，检索规模测试决定是否需要调整存储算法。
- 2026-10-11用户追加邮箱自主注册：验证码验证邮箱后创建普通用户，可用邮箱登录；原用户名账号和管理员创建账号保留。管理员创建/重置临时密码仍强制修改。SMTP实际接入留到服务器部署，本地用管理员邮件预览。
- 认证采用 Argon2id、服务端 Cookie 会话、CSRF；生产要求 HTTPS。
- 平台模型支持管理员许可的 Ollama 和 OpenAI 兼容 API；个人支持 OpenAI 兼容 API，私网地址禁止。
- 个人备份导出与管理员全站恢复纳入本版；个人恢复不开放，原整库恢复接口不给普通用户。
- PostgreSQL 持久化任务，独立 worker，租约/心跳和用户公平调度；不增加 Redis。
- 密钥认证加密，主密钥配置注入，不在 Git 保存；真实 API 验证需专门授权凭据。
- 公网服务器与域名尚未提供，最后交付生产配置与本地验证，公网验收单独记为待条件就绪。
- Docker Hub 在当前网络不可达，使用可达镜像源获取相同 digest 的基础镜像，不更改系统代理/DNS。

私有基线备份放在 `.runtime/v1-baseline`，不含 secret，Git 忽略。
