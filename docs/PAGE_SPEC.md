# 第一版页面规格

参考窗口 1440×900，支持常见桌面 1280×720；左侧导航 200px，顶部上下文栏 64px。内容区至少 24px 留白。只支持桌面，不新增移动端。

| 页面 | 主体布局 | 主要操作 |
| --- | --- | --- |
| 首页 | 顶部快速提问，下方最近对话和统计双栏，底部最近资料 | 范围选择、开始提问、继续对话、状态筛选跳转 |
| 知识库 | 知识库选择与搜索，导入区，状态筛选，分页文档表格 | 创建/重命名/删除知识库、拖拽批量上传、重复决策、预览/替换/删除 |
| 文档详情 | 名称与状态，预览/解析与片段/处理信息标签 | PDF 页定位、片段分页、重试/重建、参数修改 |
| 文档处理 | 状态统计、任务过滤和任务卡片 | 查看阶段与数量、错误原因、重试、索引影响与重建 |
| 问答 | 对话列表 220px，中间弹性对话区，来源 320px 可收起 | 搜索/新建/重命名/删除对话、模型/范围选择、停止/复制/重新生成、引用定位 |
| 设置 | 模型/数据/偏好标签 | 两种用途独立模型配置与测试，下载进度，备份恢复与清理，偏好保存 |

对话来源面板展开时正文最小 400px；空间不足时来源面板作为工作区内覆盖面板打开，可关闭。页面不横向裁切主操作。

| 状态 | 界面行为 |
| --- | --- |
| 首次空数据 | 显示导入及模型设置入口，统计为真实的 0 |
| 模型未配置 | 保留问题输入，阻止提交，解释并链接到对应用途设置 |
| 上传中 | 逐文件状态，禁止同一请求重复提交 |
| 解析失败 | 文档/任务均可查看具体原因，支持单独重试 |
| 待重建 | 说明配置变化，索引不可用并给出重建入口 |
| 排队 | 显示等待本地模型资源，允许停止生成 |
| 生成中 | 分段显示，停止可用，输入与历史不丢 |
| 断网/API失败 | 明确失败原因，保留问题，不自动重发或回退 |
| 恢复中 | 显示维护状态，阻止修改，完成后刷新真实数据 |
| 后端不可用 | 显示连接失败与重试，不将其显示为资料已删除 |

文件来源和引用快照用独立记录保存；UI 不把文档删除视为历史引用清空。删除与覆盖恢复显示影响数量与确认操作。
