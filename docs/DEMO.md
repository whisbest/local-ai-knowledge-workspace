# 第一版演示

1. 双击 start.cmd，在设置页添加并测试两个本地配置，设为默认。
2. 新建“学习”知识库，导入自己的 TXT/MD/DOCX/文字 PDF。查看各文件任务状态；损坏文件单独失败，可重试。
3. 在资料详情检查来源位置、切片和 PDF 页码，处理页查看向量数与重建。
4. 首页选择知识库并输入资料中的问题，进入对话，展开引用和本次检索，再继续提问。
5. 提问资料外问题，检查资料不足说明。刷新不会重新生成，复制/停止/重新生成均可操作。
6. 替换或删除来源，新提问不能使用旧版本；历史回答仍保留当时片段，并注明删除或替换。
7. 备份下载到本机，在隔离目录恢复，检查文件/索引/对话/引用，补齐模型或密钥。
8. 双击 stop.cmd，再 start.cmd，所有已保存数据仍存在。

测试样本 `tests/fixtures` 只用于公开演示或独立测试，不会自动加入正式知识库。真实模型实测问题和耗时在 `.reports/stage5-real.json`、`.reports/stage8-docker-real.json`。
